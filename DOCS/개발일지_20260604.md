#### 4-2. GSAP Magnetic 효과
- **GSAP 3.12** CDN 추가
- Contact 버튼 3개: `overwrite:"auto"` magnetic — 마우스 추적 후 `elastic.out` 스프링백
- 프로필 사진: `rotationX/Y` 3D tilt + magnetic 이동 + `img` float 분리

**`overwrite:"auto"` 적용 이유**  
x/y 속성이 충돌하는 경우에만 선택적으로 기존 트윈을 종료하므로,  
사진 float(y축)와 magnetic(x,y축)이 서로 간섭 없이 동작한다.

## 학습 포인트

1. **HTML 구조화**: 시맨틱 태그(header, nav, main, section, footer) 사용 방법
2. **CSS 변수 시스템**: `--primary`, `--event` 등으로 테마 전환 아키텍처 구성
3. **JavaScript DOM 조작**: `querySelector`, `addEventListener`, `classList`
4. **Canvas API**: `requestAnimationFrame` 루프, 2D 컨텍스트 드로잉
5. **GSAP 트윈**: `gsap.to()`, `overwrite:"auto"`, `elastic.out` ease
6. **Git 워크플로우**: commit → push → GitHub Actions 자동 빌드·배포
7. **OG / SEO**: 소셜 미리보기를 위한 메타데이터 구성 원리
8. **UX 일관성**: 네비 순서와 본문 섹션 순서를 일치시키는 중요성
9. **CSS 레이아웃 설계**: Flexbox `flex-direction: row` 로 좌우 분할, `order`로 모바일 재배치
10. **URL 인코딩**: 비ASCII 문자(한글)를 URL에 사용할 때 퍼센트 인코딩 필수
11. **장애 대응**: `curl`로 외부 서비스 응답 직접 확인 → 대체 서비스 탐색 및 검증
