#### 4-2. GSAP Magnetic 효과 (`155c121`)
- **GSAP 3.12** CDN 추가
- Contact 버튼 3개: `overwrite:"auto"` magnetic — 마우스 추적 후 `elastic.out` 스프링백
- 프로필 사진: `rotationX/Y` 3D tilt + magnetic 이동 + `img` float 분리
- 입장 애니메이션: CSS keyframe → GSAP `to()` 전환

**`overwrite:"auto"` 적용 이유**  
x/y 속성이 충돌하는 경우에만 선택적으로 기존 트윈을 종료하므로,  
사진 float(y축)와 magnetic(x,y축)이 서로 간섭 없이 동작한다.

### 5. 5가지 컬러 팔레트 테마 시스템 (16:41)

#### 설계 원칙
- `style.css`: 레이아웃·구조 전용, 색상 하드코딩 없음
- `themes/*.css`: 팔레트별 CSS 변수 정의
- WCAG AA 기준 텍스트 대비비 **4.5:1 이상** 모든 테마에서 검증

#### 5가지 팔레트
| 파일 | 주컬러 | 보조(페어) | 이벤트 |
|------|--------|-----------|--------|
| `green.css` | 다크 그린 `#166534` | 연두 `#4ade80` | 옐로우 `#facc15` |
| `blue.css` | 다크 블루 `#1e3a5f` | 로열 블루 `#3b82f6` | 옐로우 |
| `purple.css` | 다크 퍼플 `#4c1d95` | 라벤더 `#a78bfa` | 옐로우 |
| `red.css` | 다크 레드 `#7f1d1d` | 코랄 `#f87171` | 옐로우 |
| `slate.css` | 다크 슬레이트 `#1e3a4c` | 스카이 `#38bdf8` | 옐로우 |

#### 다크 모드
- `prefers-color-scheme: dark` 자동 감지
- 주컬러: 어두운 배경에서 밝은 계열로 자동 전환 (예: `#166534` → `#4ade80`)
- 이벤트 컬러: 밝은 노랑 `#facc15` 유지

#### 팔레트 피커 UI
- 우하단 고정 플로팅 버튼
- 클릭 시 5개 스와치 패널 표시
- 선택한 테마 `localStorage` 저장 → 새로고침 후에도 유지
